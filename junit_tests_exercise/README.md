# JUnit Tests Exercise

A Java project for practicing unit testing with JUnit 5.

The project includes a simple calculator and a library management system where users can add, remove, and search for books.

Unit tests are written for the `Calculator`, `Book`, and `Library` classes.

## How to Run

The project uses Java 21 and Maven.

Run `Main.java` to use the library system, or run the tests using:

```bash
mvn test
```
