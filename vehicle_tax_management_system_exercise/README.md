# Vehicle Tax Management System

A Java console application for managing vehicles, their owners, and annual vehicle taxes.

The system allows users to:

- Add, edit, delete, and search for people and vehicles.
- Assign vehicles to owners and transfer ownership.
- Calculate annual taxes for cars and motorcycles.
- Generate annual tax reports.

The data is stored in memory and is lost when the program closes.

## How to Run

Compile the Java files and run the main class:

```bash
javac -d out src/*.java
java -cp out Main
```

To run the example scenario:

```bash
java -cp out Main --demo
```

The assignment instructions and UML diagrams are also included in the folder.
