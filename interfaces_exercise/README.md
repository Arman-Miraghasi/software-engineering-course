# Interfaces Exercise

This project contains Java exercises about interfaces and sorting objects.

Two different approaches are implemented:

- **Question 8:** Sorting people and rectangles using a custom `Sortable` interface and bubble sort.
- **Question 10:** Sorting the same objects using Java's `Comparable` interface and `Collections.sort()`.

## How to Run

Run `MainQ8.java` or `MainQ10.java` to see the results.

The exercise instructions and diagrams are also included in the folder.
